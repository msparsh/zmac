# Zmac

A small, candy-colored arithmetic practice game built with Flutter.

Choose a mix of addition, subtraction, multiplication, and division; adjust
number ranges and the round length; then type each answer. Correct answers
advance immediately. A round tracks score, accuracy, streak, response time,
operation breakdowns, misses, and an individual problem trail.

## Run

```sh
flutter pub get
flutter run -d windows
```

Press `r` in the Flutter terminal to hot reload changes.

## Verify

```sh
flutter analyze
flutter test
```
